# Project Information for Claude

## Project Overview
CoREd is a multi-platform user interface application for CoRE (Constrained RESTful Environments) and CoAP (Constrained Application Protocol). The project provides a comprehensive, cross-platform GUI tool for CoAP development and testing across multiple frameworks including Flutter, Ionic, React Native, React, Angular, Electron, Xcode/Swift, JavaFX, and Qt5. It includes a SwiftCoAP library with client/server examples, making it a complete CoAP protocol implementation and testing tool for constrained devices and IoT networks.

## Other CoAP/CoRE Tools & Resources

### Command Line Tools
- [**coap-cli**](https://github.com/coapjs/coap-cli) - Node.js based CoAP command line client
- [**libcoap-tools**](https://github.com/obgm/libcoap) - C library with coap-client/coap-server utilities
- [**CoAPthon**](https://github.com/Tanganelli/CoAPthon) - Python CoAP library with CLI tools

### Desktop Applications
- [**Copper (Cu)**](https://github.com/mkovatsc/Copper4Cr) - Firefox/Chrome browser extension for CoAP
- [**CoAP Testing Tool**](https://github.com/kb2ma/cotel) - Various standalone GUI applications

### Libraries & Frameworks
- [**libcoap**](https://github.com/obgm/libcoap) (C/C++)
- [**node-coap**](https://github.com/coapjs/node-coap) (Node.js)
- [**CoAPthon**](https://github.com/Tanganelli/CoAPthon) (Python)
- [**go-coap**](https://github.com/plgd-dev/go-coap) (Go)
- [**Californium**](https://github.com/eclipse-californium/californium) (Java)
- [**cantcoap**](https://github.com/staropram/cantcoap) (Arduino/embedded)

### Online Tools & Platforms
- [**CoAP.me**](https://coap.me/) - Public CoAP test server
- [**Eclipse Leshan**](https://github.com/eclipse-leshan/leshan) - LwM2M server with CoAP support
- Various IoT platform integrations (AWS IoT, Azure IoT)
- Packet analyzers with CoAP support (Wireshark)
